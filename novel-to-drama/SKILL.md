# 小说转短剧剧本生成器

## 核心能力

将用户提供的**小说原文片段**转换为符合抖音/快手短剧平台标准的高质量拍摄剧本，严格遵循"3秒抓眼、30秒冲突、60秒反转、结尾强钩子"的短剧黄金法则。

## 使用流程

### Step 1: 识别小说类型

根据小说内容特征，识别所属类型（可多选）：

| 类型     | 核心特征           |
| ------ | -------------- |
| 重生复仇爽文 | 主角死亡后重生、复仇打脸   |
| 霸总甜宠文  | 霸道总裁、甜蜜互动、误会虐恋 |
| 悬疑惊悚文  | 灵异事件、推理悬疑、恐怖氛围 |

### Step 2: 应用提示词模板

1. 读取 `references/core-prompt.md` 获取**核心通用提示词**（必须应用）
2. 根据识别的类型，读取对应类型提示词：
   - 重生复仇：`references/rebirth-prompt.md`
   - 霸总甜宠：`references/romance-prompt.md`
   - 悬疑惊悚：`references/thriller-prompt.md`
3. 如有进阶要求，追加 `references/advanced-prompt.md`

### Step 3: 生成剧本

**输入**：用户粘贴的小说原文片段

**输出格式**（三段式）：

```
【改编说明】
简要说明改编思路、保留/砍掉的内容及原因

【第X集】
【场景】具体地点+时间
【镜头】景别+运镜
【人物】姓名（年龄/身份/状态）
【动作】用【】包裹
【台词】直接写，不加引号
【音效/旁白】用（）包裹，不超过10字/条

【拍摄小贴士】
给拍摄者的1-2条关键建议
```

### Step 4: 迭代优化

如用户有修改意见，针对性调整：

- "结尾钩子改得更刺激"
- "女主台词改得更霸气"
- "增加打脸爽点"

## 输出规范

- 单集时长：1.5-2分钟（300-400字）
- 每集镜头数：3-5个
- 单句台词：不超过15字
- 台词占比：不超过50%
- 每30秒一个小冲突/爽点
- 每集结尾必须有强钩子

## 避坑清单

- 禁止"不由得、顿时、心中暗道"等AI模板化表达
- 禁止大段环境描写和心理活动
- 禁止逻辑断裂、人物行为动机不合理
- 禁止低俗色情、擦边内容
- 禁止超过3行的连续台词
- 禁止每集结尾没有钩子
