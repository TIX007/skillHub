# 小说转红果短剧剧本生成器

## 核心能力

将用户提供的**小说原文片段**转换为符合红果短剧平台规范的高质量拍摄剧本，严格遵循"3秒抓眼、30秒冲突、60秒反转、结尾强钩子"的短剧黄金法则。支持**14种剧本类别**，内置**剧本审核功能**，输出格式清晰规范（人物、场地、描述、台词），单集内容时间1-2分钟（约300-2500字）。

### Step 3: 生成剧本

**输入**：用户粘贴的小说原文片段

**输出格式**（红果短剧标准格式）：

```
【改编说明】
简要说明改编思路、保留/砍掉的内容及原因

【第X集】
【集名】本集标题（一句话概括核心冲突）

第1场  内/外  日/夜  具体地点

人物：角色A（身份/状态）、角色B（身份/状态）

【角色A】
（动作/表情/神态描写）
台词内容。

【角色B】
（动作/表情/神态描写）
台词内容。

（音效/旁白/环境音描述）

---

第2场  内/外  日/夜  具体地点
...

【拍摄小贴士】
给拍摄者的1-2条关键建议
```

### Step 4: 剧本审核（可选）

用户可要求对生成的剧本进行审核，读取 `references/review-prompt.md` 获取审核标准，输出审核报告：

```
【剧本审核报告】

一、格式规范检查
✅/❌ 检查项：具体说明

二、内容质量评分
- 开篇冲突：X/10
- 冲突密度：X/10
- 结尾钩子：X/10
- 人物塑造：X/10
- 台词质量：X/10
- 逻辑连贯：X/10
- 情绪节奏：X/10
总分：XX/100

三、平台适配性检查

四、综合评级：S/A/B/C/D级

五、核心问题（必须修改）

六、优化建议（可选修改）

七、亮点
```

### Step 5: 迭代优化

如用户有修改意见，针对性调整：

- "结尾钩子改得更刺激"
- "女主台词改得更霸气"
- "增加打脸爽点"
- "根据审核意见修改"

## 输出规范

- 单集时长：1-2分钟
- 单集字数：300-2500字（根据情节密度灵活调整）
- 每集镜头数：3-8个
- 单句台词：不超过15字
- 台词占比：不超过50%
- 每30秒一个小冲突/爽点
- 每集结尾必须有强钩子
- 场次格式：必须标注内/外、日/夜、具体地点
- 动作和台词必须分开写

## 避坑清单

- 禁止"不由得、顿时、心中暗道"等AI模板化表达
- 禁止大段环境描写和心理活动
- 禁止逻辑断裂、人物行为动机不合理
- 禁止低俗色情、擦边内容
- 禁止超过3行的连续台词
- 禁止每集结尾没有钩子
- 禁止场次缺少内/外、日/夜标注
- 禁止动作和台词混写在同一行
