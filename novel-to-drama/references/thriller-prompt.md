# 悬疑惊悚文专属规则

在核心通用提示词基础上添加以下规则：

## 核心法则

- **第一集必须在30秒内出现第一个诡异事件/尸体**

## 氛围营造

- 多用特写镜头营造恐怖氛围
- 减少台词，多用音效和环境音
- 常用恐怖手法：
  - 突然出现的鬼影/人影
  - 镜子反射异常
  - 诡异的背景音乐
  - 突然的静音后巨响
  - 反复出现的数字/符号

## 红果短剧格式示例

```
【第1集】
【集名】午夜来电

第1场  内  夜  老旧公寓卧室

人物：陈小雨（25岁/独居女生/疲惫）

【陈小雨】
（躺在床上刷手机，突然手机震动，屏幕显示"未知号码"）
谁啊，大半夜的……

（音效：手机震动声在寂静中格外刺耳）

【陈小雨】
（犹豫了一下，接起电话）
喂？

（音效：电话那头传来沙沙的杂音，像是风吹过树叶）

【神秘声音】
（低沉、沙哑的声音，像是从很远的地方传来）
你……还记得我吗？

【陈小雨】
（猛地坐起来，脸色煞白）
你、你是谁？

【神秘声音】
（轻笑一声）
三年前的那个雨夜……你真的忘了吗？

（音效：窗外突然响起雷声，闪电照亮整个房间）

【陈小雨】
（看向窗外，发现阳台上站着一个模糊的人影）
啊——！

（画面定格在陈小雨惊恐的脸上，黑屏）
```

## 反转设计

- 每集至少1个反转
- 反转要出人意料但合乎逻辑
- 反转类型：
  - 看似好人实际坏人
  - 看似噩梦实际真实
  - 看似结束实际开始
  - 看似巧合实际阴谋

## 悬念保持

- 不要过早揭露凶手
- 保持悬念到最后
- 每个答案带来更多问题
- 让观众不断猜测"为什么"

## 恐怖类型细分

| 类型 | 核心元素 | 氛围要点 |
|------|----------|----------|
| 灵异鬼怪 | 鬼魂、祭祀、诅咒 | 阴森、诡异配乐、雾气 |
| 刑侦推理 | 尸体、凶手、证据 | 冷色调、紧张节奏 |
| 都市怪谈 | 都市传说、深夜禁忌 | 现代感+恐怖元素 |
| 密室逃脱 | 密闭空间、解谜 | 压迫感、倒计时 |

## 结尾钩子（优先使用）

1. "主角陷入新的更大危险"
2. "出现更恐怖的线索"
3. "发现死者不是第一个"
4. "凶手就在身边"
5. "自己也成为嫌疑人"
6. "最信任的人露出真面目"

## 镜头语言

```
特写·推 - 揭示重要细节（血迹、符号、表情）
全景·摇 - 展示诡异环境全貌
跟拍 - 跟随主角进入未知空间
定格 - 关键时刻的惊吓点
俯拍 - 展示被困/绝望感
```

## 音效使用

- 风声/水滴声：营造不安
- 脚步声：预示危险接近
- 突然静音：制造紧张
- 尖叫声/碎裂声：惊吓点
- 低频嗡鸣：持续压抑感
- 钟表声/倒计时：增加紧迫感

## 恐怖公式

```
10% 正常 → 30% 异常征兆 → 40% 调查/接近真相 → 50% 遭遇危险 → 60% 逃脱/发现 → 80% 更大谜团 → 100% 恐怖钩子
```
