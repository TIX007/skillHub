# 古言虐恋文专属规则

在核心通用提示词基础上添加以下规则：

## 核心法则

- **第一集必须在30秒内展示男女主的身份关系或核心矛盾**
- 古代背景的虐要结合礼教、家族、皇权等元素

## 虐点设计

| 虐点类型 | 具体表现 | 情绪效果 |
|----------|----------|----------|
| 身份悬殊 | 王爷vs庶女/将军vs丫鬟 | 委屈、卑微 |
| 政治联姻 | 被迫嫁/娶不爱的人 | 无奈、痛苦 |
| 家族仇恨 | 世仇/灭门之仇 | 纠结、撕裂 |
| 误会重重 | 信件被截/被人设计 | 心痛、绝望 |
| 生死相隔 | 战死/毒杀/殉情 | 绝望、悲壮 |

## 人物设定

| 角色 | 必备标签 |
|------|----------|
| 男主 | 权倾天下/深情隐忍/不善表达 |
| 女主 | 坚韧/聪慧/不卑不亢 |
| 恶毒女配 | 心机深/手段狠/身份高 |
| 反派势力 | 朝堂/后宫/家族 |

## 古言元素

- 场景：宫殿、庭院、闺房、战场、牢狱
- 道具：玉佩、信物、圣旨、毒药、匕首
- 身份：王爷、将军、皇后、嫡女、庶女
- 冲突：夺嫡、争宠、复仇、保家卫国

## 结尾钩子（优先使用）

1. "圣旨/皇命下达，被迫分离"
2. "真相揭开，但误会更深"
3. "中毒/受伤，生死未卜"
4. "敌军来犯，男主出征"
5. "发现幕后黑手就在身边"

## 禁忌

- 禁止现代思维硬套古代背景
- 禁止过度渲染封建糟粕（三从四德等）
- 禁止女主无底线忍让
