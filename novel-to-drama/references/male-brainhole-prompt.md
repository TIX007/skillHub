# 男频脑洞文专属规则

在核心通用提示词基础上添加以下规则：

## 核心法则

- **第一集必须在30秒内展示核心脑洞设定（金手指/系统/异能觉醒）**
- 脑洞设定要简单直白，一句话能说清

## 脑洞类型

| 类型 | 核心元素 | 爽点设计 |
|------|----------|----------|
| 系统流 | 获得神秘系统、任务奖励 | 升级打怪、属性暴涨 |
| 重生流 | 回到过去、先知先觉 | 提前布局、碾压对手 |
| 穿越流 | 现代知识古代用 | 科技碾压、认知差 |
| 无敌流 | 开局满级、碾压一切 | 装逼打脸、实力碾压 |
| 透视/鉴宝 | 获得特殊能力 | 捡漏暴富、打脸质疑者 |

## 爽点设计

- 每集至少1个爽点：打脸/升级/暴富/获宝
- 爽点要具体可量化：赚了多少钱、升了多少级、打了谁的脸
- 旁观者震惊反应是爽点放大器
- 禁止"他很厉害"这种抽象描述，要具体展示

## 人物设定

| 角色 | 必备标签 |
|------|----------|
| 男主 | 扮猪吃虎/深藏不露/关键时刻爆发 |
| 反派 | 嚣张跋扈/狗眼看人低/自取其辱 |
| 女主 | 识货/慧眼识珠/被男主吸引 |
| 小弟 | 忠诚/逐渐崇拜/关键时刻助攻 |

## 结尾钩子（优先使用）

1. "新的更强对手出现"
2. "系统发布新任务/新能力解锁"
3. "发现更大秘密/宝物"
4. "反派请来更厉害的靠山"
5. "男主真实身份即将暴露"

## 禁忌

- 禁止男主无脑开后宫
- 禁止过度冗长的升级数值描写
- 禁止无意义的日常水剧情
