# 女频脑洞文专属规则

在核心通用提示词基础上添加以下规则：

## 核心法则

- **第一集必须在30秒内展示女主的特殊能力/身份/处境**
- 脑洞要与情感线结合，不能纯炫技

## 脑洞类型

| 类型 | 核心元素 | 爽点设计 |
|------|----------|----------|
| 重生复仇 | 带着记忆回到过去 | 精准复仇、改变命运 |
| 穿书 | 穿入书中世界 | 改写剧情、利用先知 |
| 读心术 | 能听到他人内心 | 识破阴谋、精准反击 |
| 空间/金手指 | 获得随身空间/系统 | 种田经商、逆袭致富 |
| 替嫁/冲喜 | 被迫嫁入豪门 | 逆袭翻身、打脸众人 |

## 爽点设计

- 女主的智慧和能力要通过具体事件展示
- 每集至少1个打脸/逆袭/获认可的爽点
- 男主对女主的态度转变是重要爽点
- 旁人的态度从轻视到震惊是爽点放大器

## 人物设定

| 角色 | 必备标签 |
|------|----------|
| 女主 | 聪明/独立/不圣母/有底线 |
| 男主 | 识货/护短/外冷内热 |
| 恶毒女配 | 嫉妒/陷害/自食其果 |
| 恶毒家人 | 势利/偏心/最终后悔 |

## 结尾钩子（优先使用）

1. "女主的新能力/身份即将暴露"
2. "更大的阴谋浮出水面"
3. "男主发现女主的秘密"
4. "新的敌人/挑战出现"
5. "女主设下陷阱，反派即将入局"

## 禁忌

- 禁止女主过度圣母/白莲花
- 禁止女主靠男人解决问题
- 禁止无脑恋爱脑
