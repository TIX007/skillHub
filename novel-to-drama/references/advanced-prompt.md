# 进阶优化提示词

在核心通用提示词基础上添加以下要求，用于提升剧本质量：

## 1. 镜头语言丰富性

合理使用不同景别和运镜方式：

| 景别 | 用途 | 关键词 |
|------|------|--------|
| 特写 | 细节、表情、关键物品 | 聚焦、放大 |
| 近景 | 人物上半身、对话 | 亲密感 |
| 中景 | 人物全身、动作 | 展示肢体语言 |
| 全景 | 环境、场面、关系 | 建立空间感 |
| 远景 | 大场面、氛围 | 烘托情绪 |

| 运镜 | 效果 | 使用场景 |
|------|------|----------|
| 推 | 聚焦、紧张、压迫 | 揭示秘密、逼近危险 |
| 拉 | 拉开、释放、揭示 | 展示全貌、情绪爆发 |
| 摇 | 扫视、环绕、眩晕 | 展示环境、恐怖氛围 |
| 跟拍 | 跟随、紧张、临场 | 追逐、解谜（必须声明几何模式：尾随/前导/侧随平行/弧线/环绕/渐近/渐远） |
| 固定 | 稳定、观察、压迫 | 审讯、对峙、等待 |
| 俯拍 | 渺小、绝望、掌控 | 展示困境、胜利者视角 |
| 仰拍 | 威严、压迫、强大 | 反派出场、霸总登场 |

## 2. 情绪递进设计

每集情绪要有起伏：

```
平静 → 异常征兆 → 小冲突 → 大冲突 → 情绪爆发 → 悬念结尾
```

**示例节奏（2分钟/集）**：

- 0-15秒：平静/日常（建立氛围）
- 15-45秒：异常征兆（埋下伏笔）
- 45-75秒：小冲突（第一波爽点）
- 75-105秒：大冲突/高潮（核心爽点）
- 105-120秒：悬念结尾（强钩子）

## 3. 伏笔埋设

在前面集数埋下后面剧情的伏笔：

```
第1集：女主手腕有神秘伤疤（第3集揭示是重生印记）
第2集：男配送给女主一个旧手机（第5集成为关键证据）
第3集：墙上日历圈出一个日期（第7集是真相揭露日）
```

**伏笔类型**：

- 物品伏笔：某个物品后面成为关键道具
- 话语伏笔：一句无心之语后来被证实
- 表情伏笔：某人诡异表情暗示身份
- 数字伏笔：某个数字反复出现
- 位置伏笔：某个地点反复出现

## 4. 台词比例控制

- 台词占比不超过50%
- 剩下50%用动作、表情、音效表达
- 一集2分钟，台词不超过60秒

## 5. 竖屏适配

所有镜头考虑竖屏构图：

```
✓ 重点突出人物上半身
✓ 人物居中或偏下（留上部空间）
✓ 特写镜头更适用
✓ 减少横向调度
✓ 避免需要横向运动的场景
```

## 6. 爆款短剧参考

如果用户提供参考片段，学习其节奏和风格：

```
学习维度：
- 开场方式（前3秒如何抓眼球）
- 冲突密度（多少秒一个爽点）
- 台词风格（口语化程度、情绪强度）
- 镜头节奏（切换频率、时长分配）
- 钩子设计（结尾处理方式）
```

## 7. 红果短剧格式进阶技巧

### 场次转换技巧

- 用动作结尾：上一场最后一个动作直接切到下一场
- 用台词呼应：上一场最后一句台词在下一场有回应
- 用音效过渡：用音效连接两个不同场景
- 用对比转换：快乐→悲伤、白天→黑夜

### 人物出场技巧

- 重要人物第一次出场要有"亮相"：用特写+音效+旁白
- 重要人物首次出场采用**预兆性角色引入链**：预兆信号（局部/阴影/倒影/他人反应/物件/声音）→ 视线匹配/主体交接过渡 → 跟拍几何揭示本体，禁止直接全景亮相
- 反派出场要有"压迫感"：用仰拍+低沉音效+阴影引入
- 女主出场要有"记忆点"：用特定动作/台词标签

### 情绪放大技巧

- 关键台词重复：在不同场景重复同一句台词，情绪递进
- 动作对比：同样的动作，不同的情绪表达
- 时间压缩/拉伸：关键瞬间慢放，平淡时光快进

## 8. 质量检查清单

生成后自检：

- [ ] 开篇3秒有强冲突？
- [ ] 每30秒有爽点？
- [ ] 结尾有强钩子？
- [ ] 单句台词≤15字？
- [ ] 台词占比≤50%？
- [ ] 无AI模板化表达？
- [ ] 无超过3行连续台词？
- [ ] 人物标签够鲜明？
- [ ] 场次格式规范？（内/外、日/夜、地点）
- [ ] 动作和台词分开写？
- [ ] 单集字数在300-2500范围内？
- [ ] 每场有【运镜】主镜头标注？
- [ ] 高光动作有〔镜头：xxx〕行内标注（每集2-4处）？
- [ ] 跟拍全部声明几何模式，无"镜头跟着跑"式模糊表述？
- [ ] 重要人物首次出场采用预兆性引入链？
