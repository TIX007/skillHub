# 重生复仇爽文专属规则

在核心通用提示词基础上添加以下规则：

## 核心法则

- **第一集必须在30秒内完成"死亡→重生→立誓复仇"的完整闭环**

## 爽点设计

- 每集至少1个打脸爽点
- 打脸要直接、干脆，不要拖泥带水
- 反派的嚣张程度和被打脸的惨度成正比
- 越嚣张，打脸越爽

## 智商碾压

- 强化女主/男主的智商碾压
- 不要靠运气和巧合
- 让主角用智慧和布局战胜对手

## 红果短剧格式示例

```
【第1集】
【集名】重生归来

第1场  内  夜  豪华别墅卧室

人物：林晚（28岁/重生女主/浑身是血）、周子轩（30岁/渣男前夫/冷漠）

【林晚】
（倒在血泊中，看着面前的两个人，眼神充满绝望）
你们……会遭报应的。

【周子轩】
（蹲下身，捏住林晚的下巴，冷笑）
报应？林晚，你太天真了。

（音效：心跳声逐渐停止）

---

第2场  内  日  大学宿舍

人物：林晚（22岁/大学时期/猛然惊醒）

【林晚】
（猛地从床上坐起，大口喘气，摸了摸自己的脸和身体）
我……没死？

（旁白：她回到了六年前，一切噩梦开始之前。）

【林晚】
（看着镜子里年轻的自己，眼神逐渐变得冰冷）
这一次，我要让你们付出代价。
```

## 结尾钩子（优先使用）

1. "反派即将发现真相"
2. "下一个复仇目标出现"
3. "主角设下陷阱，反派即将入局"
4. "神秘人出现，局势突变"

## 结构模板

### 第1集标准结构（60秒闭环）

```
[0-10秒] 死亡场景 - 主角被背叛、推下悬崖等
[10-30秒] 重生醒来 - 回到关键时间点
[30-50秒] 立誓复仇 - 确认身份、目标
[50-60秒] 第一个钩子 - 反派或相关人物出现
```

### 打脸爽点公式

```
1. 反派嚣张挑衅（10秒）
2. 主角冷笑/淡定回应（5秒）
3. 证据/实力展示（10秒）
4. 反派被打脸/崩溃（10秒）
5. 周围人震惊反应（5秒）
```

## 人物强化

| 角色 | 性格放大 | 必备标签 |
|------|----------|----------|
| 重生主角 | 冷静、计算、狠辣 | 隐忍腹黑/霸气回归 |
| 第一反派 | 嚣张、愚蠢、恶毒 | 坏事做绝/即将倒霉 |
| 帮凶 | 谄媚、墙头草 | 见风使舵/最先倒霉 |
| 白月光/忠犬 | 真诚、守护 | 不离不弃/终于被看见 |
