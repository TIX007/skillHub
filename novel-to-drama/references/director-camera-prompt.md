# 导演运镜手法手册（转剧本时嵌入标注）

## 角色定位

你同时具备导演视角：在完成剧本创作的同时，为每一场、每一个关键镜头标注**导演运镜手法**，让剧本从"文字可拍"升级为"镜头语言可直接执行"。运镜标注不是可选项，是每场的标配元素。

---

## 一、运镜标注格式规范

### 场级标注

每场标题行后、人物行前，插入一行【运镜】标注本场核心运镜方案：

```
第1场  内  夜  废弃厂房

【运镜】本场主镜头：仰拍+缓慢推近（反派登场压迫感）；辅镜头：特写（女主攥紧的手）

人物：林晚（25岁/重生女主/警觉）、赵擎（40岁/反派/嚣张）
```

### 关键动作行内标注

角色动作行末尾可追加 `〔镜头：xxx〕`，只在高光动作/钩子动作处使用，避免全篇堆砌：

```
【林晚】（缓缓睁开眼，嘴角勾起冷笑）〔镜头：特写→慢推，眼神由涣散到聚焦〕
你以为，还能再杀我一次？
```

### 转场标注

场次分隔线处可标注转接方式：`---（转接：视线匹配）`，注明上一场末尾与下一场开头的衔接逻辑。

---

## 二、基础运镜库（按叙事功能选用）

| 运镜 | 叙事功能 | 短剧使用场景 |
|------|---------|-------------|
| 推（Push in） | 聚焦、压迫、揭示 | 秘密被揭穿、情绪逼近临界点 |
| 拉（Pull out） | 释放、孤立、揭示全貌 | 打脸后反派孤立、真相全景展示 |
| 摇（Pan） | 扫视、关系揭示 | 展示围观群像、反派手下环绕 |
| 移（Track） | 平滑跟随叙事流 | 日常过渡、场景内动线展示 |
| 跟拍（Follow） | 临场感、追踪 | 追逐、跟踪、逃亡（详见跟镜头几何） |
| 升降（Crane） | 命运感、地位变化 | 登场俯升、跌落俯降 |
| 固定（Static） | 观察、压抑、对峙 | 审讯、隐忍、等待爆发 |
| 俯拍（High angle） | 渺小、被掌控 | 落败者视角、困境展示 |
| 仰拍（Low angle） | 威严、强大 | 反派出场、霸总登场、打脸时刻 |
| 希区柯克变焦（Dolly zoom） | 心理扭曲、世界崩塌 | 重生瞬间、真相冲击、背叛时刻 |

## 三、跟镜头几何模式（Tracking Shot / Follow Shot）

短剧追逐/跟踪戏必用。跟拍必须写明几何模式，禁止只写"镜头跟着跑"：

| 几何模式 | 机位与轨迹 | 短剧适用 |
|---------|-----------|---------|
| 尾随几何 | 机位在主体正后方背跟 | 跟踪偷拍、反派逼近、逃亡 |
| 前导几何 | 机位在主体前方倒退跟 | 行进中放狠话、诀别回头 |
| 侧随平行几何 | 侧面等距平行移动 | 并肩对峙行走、双人并行 |
| 弧线跟拍几何 | 弧线轨迹跟随转向 | 命运转折暗示、走廊转角遇人 |
| 环绕跟拍几何 | 以主体为圆心环绕 | 觉醒蓄力、高光打脸前定格 |
| 渐近跟拍几何 | 尾随基础上逐渐拉近 | 真相逼近、心理压迫递增 |
| 渐远跟拍几何 | 尾随基础上逐渐拉远 | 被抛弃、落败离场 |

**标注格式**：`跟拍（尾随几何，背跟，渐近）`、`跟拍（前导几何，正跟，定距）`

## 四、预兆性角色引入（Omen-led Character Introduction）

重要人物（男主、大反派、关键神秘人）首次出场禁止直接全景亮相，采用预兆性引入链三步结构：

```
第一镜（预兆信号）：以下任选1-2种
  - 局部引入：手部/脚步/衣角/背影特写
  - 阴影引入：角色阴影先投射入画，本体在画外
  - 倒影引入：镜面/水面/玻璃反射先行呈现
  - 他人反应引入：配角惊恐/敬畏的表情，本体在画外
  - 物件引入：标志性物品（刀/怀表/戒指）特写先入画
  - 声音引入：画外脚步声/低笑声先行

第二镜（过渡）：视线匹配或主体交接（见转接技巧）

第三镜（揭示）：跟拍几何或升格特写完成本体亮相
```

**短剧适配建议**：

- 男主/霸总登场：物件引入（豪车钥匙/手表）+ 仰拍 → 前导几何正跟亮相
- 大反派登场：阴影引入 + 他人反应（手下低头噤声）→ 尾随几何背影 → 转正面对峙
- 神秘助力者：倒影引入 + 声音引入 → 环绕跟拍几何揭示 + 定格

## 五、转接技巧（镜头间衔接）

| 技巧 | 规则 | 短剧用法 |
|------|------|---------|
| **视线匹配（Eye-line Match）** | 上镜人物视线投画外 → 下镜切其所视目标，方向守恒（看向画左 → 目标出现在画左） | 反打对话、揭示威胁、揭示新角色 |
| **主体交接（Subject Handoff）** | 上镜背景/边缘次要元素 → 下镜放大为中心主体 | 围观人群中的关键证人、背景一闪而过的跟踪者 |
| 动作转接 | 上一场末动作直接延续到下一场开场 | 追逐跨场景、耳光接踉跄 |
| 台词呼应 | 上一场末句台词在下一场被回应 | 悬念跨场延续 |
| 音效过渡 | 音效先行连接两个场景 | 尖叫/刹车声转场 |

**标注格式**：`---（转接：视线匹配，女主视线投画左，下场目标自画左入画）`

## 六、钩子与爽点运镜配置表

| 剧情节点 | 推荐运镜组合 |
|---------|-------------|
| 开篇3秒冲突 | 快速推近 + 特写，直接怼脸冲突点 |
| 打脸时刻 | 希区柯克变焦（对方世界崩塌）+ 仰拍（主角威压） |
| 耳光/肢体冲突 | 120帧升格特写 + 定格 |
| 反派嚣张 | 仰拍缓推 + 压迫式近景 |
| 女主觉醒 | 环绕跟拍几何 + 缓慢升拉 + 眼部特写慢推 |
| 结尾强钩子 | 渐近跟拍几何（威胁逼近）或急推 + 黑屏定格 |

## 七、竖屏适配运镜约束

- 优先纵向运动：推/拉/升/降优于横移/横摇
- 跟拍几何优先选：尾随、前导、渐近（纵向动线），慎用长距离侧随平行
- 环绕跟拍几何限制弧度：不超过 90°，避免主体出框
- 特写占比提高：竖屏特写冲击力最强，运镜落点尽量收在特写

## 八、运镜标注密度控制

- 每场 1 条主镜头标注（必填）
- 每集高光动作行内标注 2-4 处（只标钩子、打脸、反转、登场）
- 转接标注只用于跨场景衔接有叙事逻辑的场次，普通直切不标
- 运镜术语必须来自本手册词库，禁止"有氛围感的镜头"等模糊表述
