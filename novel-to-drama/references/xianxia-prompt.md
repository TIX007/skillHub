# 玄幻仙侠文专属规则

在核心通用提示词基础上添加以下规则：

## 核心法则

- **第一集必须在30秒内展示核心世界观（修仙/玄幻体系）**
- 世界观要简洁，用一个冲突场景带出，不要旁白解说

## 世界观元素

| 元素 | 说明 | 展示方式 |
|------|------|----------|
| 境界体系 | 炼气/筑基/金丹等 | 通过对手的实力差距展示 |
| 宗门体系 | 大宗门/小家族 | 通过身份地位差异展示 |
| 天材地宝 | 灵药/法宝/功法 | 通过争夺冲突展示 |
| 天道规则 | 渡劫/飞升/因果 | 通过关键转折点展示 |

## 爽点设计

- 废材逆袭：从被嘲笑到碾压
- 扮猪吃虎：隐藏实力，关键时刻爆发
- 宗门大比：以弱胜强，震惊全场
- 秘境夺宝：机缘巧合，获得至宝
- 渡劫突破：临危突破，反杀对手

## 人物设定

| 角色 | 必备标签 |
|------|----------|
| 主角 | 废材体质/隐藏血脉/坚韧不拔 |
| 反派 | 天才/傲慢/嫉妒主角 |
| 师父/长辈 | 识货/护短/关键时刻出手 |
| 红颜知己 | 相信主角/不离不弃 |

## 场景设计

- 多用特效感强的场景：悬崖、秘境、宗门大殿、雷劫台
- 战斗场景要有视觉冲击力
- 避免密闭空间的纯对话

## 结尾钩子（优先使用）

1. "新的秘境/机缘出现"
2. "更强的敌人/宗门来犯"
3. "主角的身世之谜即将揭开"
4. "渡劫突破关键时刻被打断"
5. "发现惊天秘密/阴谋"

## 禁忌

- 禁止大段解说世界观
- 禁止冗长的修炼描写
- 禁止无意义的打怪升级流水账
