# 女性成长文专属规则

在核心通用提示词基础上添加以下规则：

## 核心法则

- **第一集必须在30秒内展示女性主角的困境/觉醒时刻**
- 成长要有具体事件支撑，不能空喊口号

## 成长阶段

```
困境/压迫 → 觉醒/反抗 → 挣扎/挫折 → 突破/成长 → 独立/绽放
```

## 成长类型

| 类型 | 初始困境 | 成长方向 |
|------|----------|----------|
| 职场成长 | 被打压/被忽视 | 独当一面 |
| 情感觉醒 | 依附他人/恋爱脑 | 经济情感独立 |
| 家庭突围 | 原生家庭/重男轻女 | 打破枷锁 |
| 自我发现 | 迷茫/随波逐流 | 找到自我价值 |
| 逆境重生 | 重大打击/人生低谷 | 浴火重生 |

## 人物设定

| 角色 | 必备标签 |
|------|----------|
| 女主 | 有潜力/需要觉醒/最终绽放 |
| 阻碍者 | 不理解/阻挠/代表旧观念 |
| 引路人 | 点醒/帮助/提供机会 |
| 同路人 | 互相扶持/共同成长 |

## 场景设计

- 职场办公室、家庭餐桌、出租屋、医院
- 多用细节展示成长：从低头到抬头、从沉默到发声
- 对比场景：同样的场景，不同的回应方式

## 结尾钩子（优先使用）

1. "面临重大选择/考验"
2. "新的挑战/机遇出现"
3. "旧关系需要重新定义"
4. "发现自己的真正价值"
5. "帮助其他女性觉醒"

## 禁忌

- 禁止空喊口号式的女性主义
- 禁止把成长简单等同于赚钱/变美
- 禁止丑化所有男性角色
