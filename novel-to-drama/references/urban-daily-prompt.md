# 都市日常文专属规则

在核心通用提示词基础上添加以下规则：

## 核心法则

- **第一集必须在30秒内展示主角的日常生活困境或转折点**
- 日常不等于平淡，要从日常中提炼冲突

## 冲突来源

| 类型 | 具体表现 | 情绪效果 |
|------|----------|----------|
| 职场 | 加班/被裁/同事算计 | 共鸣、愤怒 |
| 家庭 | 婆媳矛盾/育儿分歧/经济压力 | 焦虑、无奈 |
| 社交 | 人情往来/面子文化/攀比 | 窒息、反抗 |
| 情感 | 相亲/催婚/感情危机 | 纠结、心酸 |
| 邻居 | 噪音/占道/物业纠纷 | 生气、搞笑 |

## 人物设定

| 角色 | 必备标签 |
|------|----------|
| 主角 | 普通人/有缺点/善良但不软弱 |
| 配偶 | 有缺点但本质好/需要成长 |
| 领导/同事 | 各种职场典型人物 |
| 亲戚/邻居 | 各种社会关系缩影 |

## 场景设计

- 家庭客厅、公司工位、小区楼下、菜市场、医院
- 多用生活化细节：外卖、快递、手机消息、电梯偶遇
- 对话要接地气，用生活化的语言

## 结尾钩子（优先使用）

1. "突然接到裁员通知"
2. "发现伴侣/家人的秘密"
3. "意外获得一笔钱/一个机会"
4. "邻居/亲戚惹出大麻烦"
5. "孩子/老人突发状况"

## 禁忌

- 禁止脱离普通人生活的精英叙事
- 禁止过度贩卖焦虑
- 禁止无病呻吟、小题大做
