# 青春虐恋文专属规则

在核心通用提示词基础上添加以下规则：

## 核心法则

- **第一集必须在30秒内建立男女主的情感羁绊或矛盾**
- 虐要虐到点上，不能为虐而虐

## 情感节奏

```
甜 → 误会 → 虐 → 解开 → 更甜 → 更大的误会 → 大虐 → 和好 → 终极考验
```

## 虐点设计

| 虐点类型 | 具体表现 | 情绪效果 |
|----------|----------|----------|
| 身份差距 | 富家子弟vs穷学生 | 委屈、不甘 |
| 误会分离 | 看到不该看的、听到不该听的 | 心痛、绝望 |
| 第三者介入 | 前任/相亲对象/青梅竹马 | 嫉妒、不安 |
| 家庭阻挠 | 父母反对、门不当户不对 | 无奈、抗争 |
| 生死离别 | 重病/意外/出国 | 绝望、珍惜 |

## 人物设定

| 角色 | 必备标签 |
|------|----------|
| 男主 | 外冷内热/默默付出/不善表达 |
| 女主 | 善良/敏感/容易误会 |
| 情敌 | 温柔/完美/但不是真爱 |
| 闺蜜/兄弟 | 旁观者清/助攻/吐槽 |

## 甜虐比例

- 前期：甜7虐3（建立感情基础）
- 中期：甜3虐7（制造矛盾冲突）
- 后期：甜8虐2（和好收尾）

## 结尾钩子（优先使用）

1. "误会加深，两人越走越远"
2. "情敌趁虚而入"
3. "家庭变故，被迫分离"
4. "真相即将揭开，但代价很大"
5. "一方做出重大牺牲"

## 禁忌

- 禁止无脑虐，虐要有合理原因
- 禁止女主过度卑微/舔狗
- 禁止男主渣男行为被美化
