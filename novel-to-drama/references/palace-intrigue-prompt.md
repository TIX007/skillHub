# 宫斗宅斗文专属规则

在核心通用提示词基础上添加以下规则：

## 核心法则

- **第一集必须在30秒内展示后宅/后宫的等级压迫和核心矛盾**
- 斗争要讲策略，不能纯靠运气

## 斗争类型

| 类型 | 核心元素 | 斗争方式 |
|------|----------|----------|
| 宫斗 | 后宫嫔妃争宠 | 下毒、栽赃、拉拢、示弱 |
| 宅斗 | 大宅院妻妾争产 | 掌家权、子嗣、嫁妆、人脉 |
| 家族 | 嫡庶之争 | 继承权、联姻、站队 |

## 斗争策略

- 借刀杀人：利用第三方对付敌人
- 以退为进：示弱引诱敌人犯错
- 反间计：让敌人内部产生矛盾
- 将计就计：识破敌人计谋后反击
- 证据链：收集证据，一击致命

## 人物设定

| 角色 | 必备标签 |
|------|----------|
| 女主 | 隐忍/聪慧/关键时刻爆发 |
| 主要对手 | 嚣张/有手段/有靠山 |
| 男主/家主 | 被蒙蔽/最终清醒 |
| 助手 | 忠心/机灵/关键时刻传递消息 |
| 墙头草 | 见风使舵/最先倒霉 |

## 场景设计

- 正厅、偏厅、花园、佛堂、厨房、库房
- 多用宅院特色：丫鬟传话、小厮报信、门缝偷听
- 请安、用膳、管家、查账都是斗争场景

## 结尾钩子（优先使用）

1. "新的对手/势力加入战局"
2. "发现更大的秘密/把柄"
3. "男主/家主态度转变"
4. "被陷害，即将受罚"
5. "设下陷阱，等待对手入局"

## 禁忌

- 禁止无脑降智，所有角色都要有智商
- 禁止女主开挂式胜利，要合理布局
- 禁止过度渲染封建等级观念
