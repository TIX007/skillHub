# 小说转红果短剧剧本生成器

将网络小说片段转换为符合红果短剧平台标准的高密度、强情绪、强钩子的短剧拍摄剧本。

## 功能特性

- **14种剧本类别**：覆盖男频脑洞、女频脑洞、悬疑惊悚、玄幻仙侠、青春虐恋、古言虐恋、历史古代、都市日常、宫斗宅斗、现言甜宠、古言甜宠、民国旧影、年代、女性成长
- **红果短剧格式**：严格遵循红果短剧剧本规范，输出格式清晰规范（人物、场地、描述、台词）
- **剧本审核功能**：内置审核系统，从格式规范、内容质量、平台适配性三个维度进行全面审核
- **单集1-2分钟**：每集约300-2500字，节奏紧凑，全程无尿点

## 使用方法

### 基本用法

1. 粘贴小说原文片段
2. 系统自动识别小说类型
3. 生成符合红果短剧规范的剧本

### 剧本审核

在生成剧本后，可要求进行剧本审核：

```
请审核这个剧本
```

系统将输出包含格式检查、内容评分、综合评级的审核报告。

### 迭代优化

根据审核意见或个人需求进行调整：

```
结尾钩子改得更刺激
女主台词改得更霸气
增加打脸爽点
```

## 剧本格式

```markdown
【第X集】
【集名】本集标题

第1场  内/外  日/夜  具体地点

人物：角色A（身份/状态）、角色B（身份/状态）

【角色A】
（动作/表情/神态描写）
台词内容。

【角色B】
（动作/表情/神态描写）
台词内容。

（音效/旁白/环境音描述）

---

第2场  内/外  日/夜  具体地点
...
```

## 输出规范

| 项目 | 标准 |
|------|------|
| 单集时长 | 1-2分钟 |
| 单集字数 | 300-2500字 |
| 每集镜头数 | 3-8个 |
| 单句台词 | 不超过15字 |
| 台词占比 | 不超过50% |
| 冲突密度 | 每30秒一个小冲突/爽点 |
| 结尾要求 | 每集结尾必须有强钩子 |

## 审核评级

| 评级 | 分数 | 说明 |
|------|------|------|
| S级 | 90-100 | 可直接拍摄，无需修改 |
| A级 | 80-89 | 小幅修改后可拍摄 |
| B级 | 70-79 | 需要较大修改 |
| C级 | 60-69 | 需要重写部分内容 |
| D级 | <60 | 需要重新改编 |

## 避坑清单

- 禁止"不由得、顿时、心中暗道"等AI模板化表达
- 禁止大段环境描写和心理活动
- 禁止逻辑断裂、人物行为动机不合理
- 禁止低俗色情、擦边内容
- 禁止超过3行的连续台词
- 禁止每集结尾没有钩子
- 禁止场次缺少内/外、日/夜标注
- 禁止动作和台词混写在同一行
