# 爆款捕手（Trend Catcher） — 使用指南

## 一句话介绍

帮你从"看到爆款只会说牛"变成"知道为什么牛、自己也能写"的自媒体内容创作助手。

## 能做什么

| 功能           | 说明                               |
| ------------ | -------------------------------- |
| 🎯 **风格定位**  | 输入你的账号领域/风格/受众，生成专属《账号风格卡》       |
| 🔥 **热文筛选**  | 自动搜索当前领域的热门顶流 + 飙升黑马文章           |
| 🔍 **爆款拆解**  | 7 个维度深度拆解：标题/开篇/结构/行文/卖点/互动/爆因   |
| 📝 **提示词生成** | 基于拆解结果，生成可反复调用的标准化创作提示词          |
| ✍️ **复刻创作**  | 借鉴风格和结构，创作全新原创文章                 |
| 🛡️ **合规审核** | 6 维度强制审核（重复率/限流/同质化/文风/阅读体验/违规词） |

## 三步上手

### 1. 设定你的账号风格

```
设定账号风格：美妆，平价好物测评，面向学生党，小红书图文
```

AI 会生成一份《账号风格卡》，包含赛道、文风、语气、句式、字数等全部定位信息。

### 2. 筛选并拆解爆款

```
开始分析爆款
```

AI 会自动搜索你所在领域的当前热门文章和飙升文章，列出清单。你选择要拆解的篇目后，AI 会对每篇做 7 维全量拆解。

### 3. 生成提示词并复刻创作

```
生成创作提示词
```

AI 基于拆解结果生成一个标准化创作提示词。之后你可以说：

```
按照风格写一篇：[你的选题]
```

AI 就会用那个提示词帮你创作一篇全新原创内容。

### 4. （必须）内容审核

```
内容审核
```

AI 会对成品做六维合规检测，输出《风控审核报告》，告诉你哪里有问题、怎么改。

## 支持的垂类

美妆 | 科技数码 | 萌宠 | 美食 | 情感 | 职场 | 育儿 | 家居 | 穿搭 | 影视娱乐 | 完全自定义

## 六步全流程

```
步骤 1：设定账号风格 → 生成《账号风格卡》
步骤 2：筛选热文 → 输出热门+飙升文章清单
步骤 3：深度拆解 → 7 维度分析爆款逻辑
步骤 4：生成创作提示词 → 标准化、可复用
步骤 5：复刻创作 → 借鉴结构，原创内容
步骤 6：合规审核 → 六维检测 + 风险定级 + 修改建议
```

每一步都可以独立使用，也可以完整走完。

## 三条红线

- ❌ 不照搬原文词句
- ❌ 不搬运素材案例
- ❌ 不洗稿批量伪原创

## 平台覆盖

适配公众号、小红书、抖音图文、头条、百家号等主流自媒体平台的通用规则。

## 常见使用场景

| 场景    | 对话示例                               |
| ----- | ---------------------------------- |
| 新号起号  | "我是做职场干货的，面向工作 1-3 年的职场新人，帮我建个风格卡" |
| 灵感枯竭  | "最近 XX 领域有什么爆款？帮我筛选一下"             |
| 学习拆解  | "这篇爆了 10 万+，帮我拆解一下为什么"             |
| 批量创作  | "用我的风格卡批量生成 3 篇关于 XX 的文章"          |
| 发布前检查 | "帮我审核这篇文章，看看有没有限流风险"               |
| 风格迭代  | "我的账号风格从干货测评改成沉浸式体验，帮我更新风格卡"       |
