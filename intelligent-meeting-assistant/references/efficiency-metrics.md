# 会议效率指标定义与基准

## 核心指标定义

### 1. 有效决策率
- **定义**：产出明确决策的会议议题数 / 总议题数 × 100%
- **计算口径**：仅统计有明确结论、责任人、生效范围的议题
- **基准**：
  - 优秀：≥80%
  - 良好：60%-79%
  - 需改进：<60%

### 2. 待办按时完成率
- **定义**：在DDL前完成的待办数 / 总待办数 × 100%
- **计算口径**：DDL当天24:00前标记完成视为按时
- **基准**：
  - 优秀：≥90%
  - 良好：70%-89%
  - 需改进：<70%

### 3. 议题重复率
- **定义**：在2次及以上会议中重复讨论的议题数 / 总议题数 × 100%
- **计算口径**：议题名称或核心内容高度相似（语义匹配度≥80%）
- **基准**：
  - 优秀：≤10%
  - 良好：11%-25%
  - 需改进：>25%

### 4. 人均发言占比
- **定义**：某参会人发言时长 / 会议总发言时长 × 100%
- **理想状态**：主持人20%-30%，其余参会人均等分布
- **异常信号**：
  - 单人发言占比>50%：讨论失衡
  - 某人发言占比<5%：参与度不足

### 5. 平均会议时长
- **定义**：周期内会议总时长 / 会议场次
- **基准**：
  - 同步会：15-30分钟
  - 讨论会：30-60分钟
  - 决策会：30-45分钟
  - 超过90分钟的会议需拆分

### 6. 会议密度
- **定义**：周期内会议总时长 / 工作总时长 × 100%
- **基准**：
  - 健康：≤30%
  - 偏高：31%-50%
  - 过载：>50%

## 问题诊断规则

### 高频无效讨论
- **触发条件**：同一议题在3次及以上会议中出现，且未形成有效决议
- **诊断输出**：议题名称、出现次数、参会角色、卡点原因
- **建议方向**：指定决策人、设置截止时间、会前对齐立场

### 过长无产出会议
- **触发条件**：会议时长>60分钟，且有效决策率<30%
- **诊断输出**：会议名称、时长、决策数、待办数
- **建议方向**：压缩议程、拆分会议、会前分发材料

### 讨论失衡
- **触发条件**：单人发言占比>50% 或 某人发言占比<5%
- **诊断输出**：会议名称、发言占比分布
- **建议方向**：主持人引导发言、设置轮流发言环节

### 待办逾期集中
- **触发条件**：某责任人待办按时完成率<50%
- **诊断输出**：责任人、逾期待办列表、逾期原因
- **建议方向**：调整DDL、减少待办量、提供支持

## 优化建议模板

### 合并重复议题
```
建议将以下议题合并为一次专题会议：
- [议题1]（出现X次）
- [议题2]（出现X次）
- [议题3]（出现X次）
预计节省时长：X分钟/周
```

### 压缩会议时长
```
[会议名称] 当前平均时长X分钟，建议压缩至Y分钟：
- 会前分发材料，减少现场阅读时间
- 聚焦核心议题，非紧急议题移至异步沟通
- 设置每议题倒计时，超时自动记录并转入下次
```

### 提升参与度
```
以下参会人近期发言占比偏低，建议关注：
- [姓名]：发言占比X%，建议在议题Y主动邀请发言
- [姓名]：发言占比X%，建议提前分配汇报任务
```
