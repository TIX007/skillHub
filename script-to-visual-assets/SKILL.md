# 剧本转视觉资产提示词专业生成技能

## 技能定位

将用户提供的剧本、场景片段、人物人设、道具描述，自动解析为可被 AI 图片模型直接识别的标准化视觉资产提示词。严格区分三类资产类型（人物/场景/道具），每类均包含固定的结构化字段与构图规范，确保输出可直接复制粘贴至 AI 图片生成工具。

三类资产共用统一的视觉风格后缀体系，可根据剧本题材自动匹配或由用户手动指定。

---

## 启动流程

### Step 1：读取并分类用户输入

用户可提供以下任意组合：

- **完整剧本**：自动提取所有人物、场景、道具，分类批量输出
- **人物人设描述**：仅生成人物形象提示词
- **场景段落描述**：仅生成场景照片提示词
- **道具描述**：仅生成道具照片提示词
- **混合输入**：包含人物+场景+道具的描述，分别输出对应类型

解析时提取以下要素：

| 资产类型 | 提取要素 |
|---------|---------|
| 人物 | 姓名、身份、性别、年龄、身高、体型、发型发质、发色、脸型、瞳色、肤色、服装（上衣/下装/鞋/帽/配饰）、特殊特征（疤痕/纹身/淤青等） |
| 场景 | 场景名称、室内/室外、景别、空间尺寸（高度/宽度）、前景背景元素、氛围基调 |
| 道具 | 道具名称、类型、形态、尺寸、材质、颜色、特殊特征（磨损/血迹/锈迹等） |

### Step 2：视觉风格匹配（自动生效，可被用户覆盖）

根据剧本题材自动匹配视觉风格，加载完整风格库参见 `references/visual-style-library.md`。

| 剧情题材 | 视觉风格后缀 |
|---------|------------|
| 现代都市 / 校园 / 悬疑 / 犯罪 | 现代都市·真人写实电影 |
| 古风仙侠 / 武侠 / 历史 | 古风仙侠·水墨工笔电影 |
| 赛博朋克 / 科幻 / 末日废土 | 赛博末日·霓虹废土电影 |
| 奇幻 / 魔幻 / 神话 | 史诗奇幻·油画质感电影 |
| 年代怀旧 / 民国 / 复古 | 复古年代·胶片质感电影 |
| 青春治愈 / 日常 / 轻喜剧 | 青春治愈·柔光清新电影 |

**覆盖规则**：用户可手动指定任意视觉风格，优先于自动匹配。用户也可自定义视觉风格后缀文本。

### Step 3：按资产类型生成提示词

根据识别的资产类型，加载对应的提示词规范：

| 资产类型 | 规范文件 | 输出结构 |
|---------|---------|---------|
| 人物形象 | `references/character-prompt-guide.md` | 名称 + 描述 + 服装 + 特征 + 构图规范 + 视觉风格 |
| 场景照片 | `references/scene-prompt-guide.md` | 名称 + 描述 + 前背景 + 氛围 + 构图规范 + 视觉风格 |
| 道具照片 | `references/prop-prompt-guide.md` | 名称 + 描述 + 特征 + 构图规范 + 视觉风格 |

每种类型的详细字段规范、视图布局规则、禁止项清单和完整模板，参见对应参考文件。

### Step 4：输出格式规范

每条资产提示词按固定字段顺序输出，字段间用换行分隔：

```
名称：<角色名/场景名/道具名>，<身份/类型简述>
描述：<结构化要素描述>
服装/前背景/特征：<对应字段>
构图规范：<完整的视图布局、光影、禁止项、一致性要求>
[视觉风格：<自动匹配或用户指定的风格后缀>]
```

**硬性规范**：
- 构图规范必须包含：视图布局结构、背景要求、光影参数、禁止项清单、一致性要求
- 视觉风格后缀必须以 `[视觉风格：...]` 格式包裹，放在提示词末尾
- 所有描述使用精准客观术语，禁止模糊形容词
- 禁止项必须显式列出，不可省略

### Step 5：多资产批量模式（完整剧本）

当用户提供完整剧本时：

1. 自动从剧本中提取所有人物、场景、道具
2. 为每个资产独立生成提示词
3. 按类型分组输出：先人物、再场景、后道具
4. 最后输出**资产总览表**：

```
| 资产编号 | 类型 | 名称 | 视觉风格 |
|---------|------|------|---------|
```

## 提示词撰写硬性规范

### 禁止使用的模糊词（自动检查并替换）

| 禁用词 | 替换为 |
|-------|-------|
| 氛围感 | 具体色调参数（如"冷青色调 4500K"） |
| 高级感 | 具体构图+光影术语（如"伦勃朗侧光，前后景分层虚化"） |
| 质感超强 | 具体材质+画质参数（如"碳纤维纹理，4K超清画质"） |
| 很精致 | "无过度曝光，画面干净，轮廓清晰" |
| 极度好看 | 具体视觉参数组合 |
| 有冲击感 | 具体构图+光影参数 |
| 神秘感 | 具体环境+光影描述（如"低照度冷调，局部点光"） |

### 强制包含项

- **人物提示词**：必须包含四视图布局（正面面部特写 + 全身正面/左侧/背面）、纯白背景、中性摄影棚灯光
- **场景提示词**：必须包含四视角网格布局（2行2列，全部3/4透视角度：左前/右前/左后/右后45度对角方位）、空场景（无人物）
- **道具提示词**：必须包含六视图布局（2行3列，正前/正后/左侧/右侧/正上俯拍/正下仰拍）、纯白背景、正交投影效果
- **所有类型**：必须包含禁止项清单、一致性要求、无文字/水印/标签/UI 元素

### 描述要素规范

**人物描述**聚焦 AI 可识别特征：性别、年龄、身高、体型、发型、发色、瞳色、肤色、服装颜色材质。不用抽象形容词。

**场景描述**聚焦 AI 可识别环境特征：室内/室外、空间尺寸、建筑结构、天气状态、时间光线、前景背景元素。不用"神秘感"等主观词。

**道具描述**聚焦 AI 可识别物理特征：形态、尺寸、材质、颜色、结构、特殊标记。不用"很酷"等主观词。

## 注意事项

- 严格贴合用户输入文本，不自行扩展人物行为或场景细节
- 人物外貌描述如用户未提供，在对应字段注明 `[请补充：缺失要素]` 占位符
- 场景提示词必须为空场景参考图，严禁出现任何人物
- 道具提示词必须为纯道具展示图，严禁出现任何人物或场景
- 三类资产的视觉风格后缀应保持一致（同一剧本/项目内统一）
- 单条提示词内不堆砌相互冲突的视觉风格
