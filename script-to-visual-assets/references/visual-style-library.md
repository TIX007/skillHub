# 视觉风格库

## 一、视觉风格后缀格式规范

所有视觉风格后缀必须以以下格式包裹，放在每条提示词末尾：

```
[视觉风格：{风格名称}。{色调描述}，{光影描述}，{画质描述}，真人。]
```

**格式约束**：
- 必须以 `[视觉风格：` 开头，以 `]` 结尾
- 风格名称使用 `·` 分隔主副标题（如 `现代都市·真人写实电影`）
- 末尾固定以 `，真人。` 结束
- 色调、光影、画质三段描述用中文逗号分隔

## 三、题材自动匹配规则

根据剧本内容关键词自动匹配视觉风格：

| 关键词特征 | 匹配风格 |
|-----------|---------|
| 学校、学生、城市、警察、悬疑、犯罪、现代、办公室 | 现代都市·真人写实电影 |
| 修仙、剑、古风、宫廷、武侠、江湖、古代、仙侠 | 古风仙侠·水墨工笔电影 |
| 赛博、机械、末日、废土、霓虹、科幻、义体、AI | 赛博末日·霓虹废土电影 |
| 奇幻、魔法、神话、龙、精灵、史诗、异世界、神力 | 史诗奇幻·油画质感电影 |
| 民国、怀旧、年代、港风、复古、1900、老上海 | 复古年代·胶片质感电影 |
| 治愈、日常、校园生活、友情、轻喜剧、温情、青春 | 青春治愈·柔光清新电影 |

**混搭规则**：同一剧本项目内所有资产（人物/场景/道具）应使用统一的视觉风格后缀，确保视觉一致性。如剧本跨题材（如"都市+仙侠"混搭），以主题材为准。

## 五、风格一致性检查清单

生成提示词后，检查以下项目确保风格一致：

- [ ] 同一项目内所有人物提示词使用相同视觉风格后缀
- [ ] 同一项目内所有场景提示词使用相同视觉风格后缀
- [ ] 同一项目内所有道具提示词使用相同视觉风格后缀
- [ ] 视觉风格后缀格式正确（`[视觉风格：...，真人。]`）
- [ ] 色调、光影、画质三段描述完整
- [ ] 风格与剧本题材匹配（或用户已确认覆盖）
