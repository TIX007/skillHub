# 场景照片提示词完整规范

## 一、输出结构（固定字段顺序）

每条场景照片提示词包含以下字段，顺序不可调换：

```
名称：<场景名>，<场景类型简述>
描述：<室内/室外>，<景别>，高度<数值>米，宽度<数值>米。
前背景：<前景元素>，<背景元素>。
氛围：<情绪基调描述>。
构图规范：<完整构图规范文本>
[视觉风格：<风格后缀>]
```

---

## 二、字段填写规范

### 名称
- 格式：`场景名，场景类型简述`
- 示例：`化工厂，废弃建筑室内` / `山巅云海，高山外景` / `审讯室，密闭空间室内`

### 描述
- 必须包含：室内/室外、景别（微观/中观/宏观/全景）、空间尺寸（高度+宽度，单位米）
- 示例：`室内，中观，高度 6 米，宽度 15 米。`

### 前背景
- 前景：镜头前方最近的可见元素
- 背景：远处环境元素
- 示例：`室内工业破败背景，生锈金属管道和积水凹坑前景。`

### 氛围
- 使用精准的情绪+色调描述，不用模糊词
- 示例：`阴森诡异，压抑沉重。` / `空旷辽远，肃穆庄严。`

## 三、构图规范（核心模块）

### 视图布局结构（全部采用 3/4 透视角度）

3/4 角度（斜45度对角方位）能同时覆盖场景的两个面（正面+侧面或背面+侧面），相比纯正面平视可展现更强的空间纵深感与全貌信息。四个视角全部采用 3/4 透视，从四个对角方位完整呈现场景全貌。

```
高质量专业场景设定图，横向构图，
以 2 行 2 列的干净网格四等分整齐排版，
每个格子都是独立的 16:9 横向画面，
展示同一场景的四个大全景视角，全部采用 3/4 透视角度以充分体现场景空间全貌：
  1 为左前方45度大全景视图：摄像机位于场景左前对角位置，以3/4角度斜向对准场景核心区域，镜头同时覆盖场景正面与左侧墙面，画面同时包含顶面与底面，展现纵深空间层次、更多环境细节和深景深
  2 为右前方45度大全景视图：摄像机位于场景右前对角位置，以3/4角度斜向对准场景核心区域，镜头同时覆盖场景正面与右侧墙面
  3 为左后方45度大全景视图：摄像机位于场景左后对角位置，以3/4角度斜向对准场景核心区域，镜头同时覆盖场景背面与左侧墙面
  4 为右后方45度大全景视图：摄像机位于场景右后对角位置，以3/4角度斜向对准场景核心区域，镜头同时覆盖场景背面与右侧墙面
四个视角从四个对角方位以3/4透视角度完整呈现场景全貌，必须表现同一地点、同一时间、同一天气、同一光源、同一空间结构和同一美术风格。
```

### 画质参数

```
环境清晰，细节丰富，景深较深，光影自然，专业摄影，超清画质。
```

### 禁止项清单（必须完整列出）

```
不得出现任何人物（这是空场景参考图，必须空无一人）；
也不得出现人群、背影、剪影、人脸、手脚、人物倒影、人物影子、照片人物、屏幕人物、镜中人物、剧情事件、人物活动；
不得让四个视角表现成四个不同场景；
不得改变建筑结构、空间比例、主体位置、材质、色彩、天气、时间段或光源方向；
画面构图不得透视畸变、广角畸变、变形、扭曲；
不得出现鱼眼视角、极端俯视、极端仰视；
四个视角必须全部采用3/4透视角度（左前/右前/左后/右后45度对角方位），禁止纯正面平视、纯背面平视或纯侧面平视；
四个视角必须保持镜头稳定、空间连贯、比例一致，3/4角度的倾斜透视程度须统一；
禁止模糊、低画质；
禁止景深太浅；
不得出现文字、水印、签名、边框、标签、UI元素、杂乱元素。
```

## 六、字段词典

### 景别描述词
微观（细节特写） / 中观（中等视野） / 宏观全景（大范围全景） / 无界（户外广阔无边际场景）

### 氛围基调词
阴森诡异，压抑沉重 / 空旷辽远，肃穆庄严 / 喧嚣压抑，光怪陆离 / 温馨舒适，宁静柔和 / 战火纷飞，紧张激烈 / 神秘幽深，静谧莫测 / 破败荒凉，寂寥萧瑟 / 金碧辉煌，庄严肃穆

### 室内/室外判定
- 室内：建筑内部空间，有顶面和墙面围合
- 室外：开放空间，无顶面围合或自然景观
- 半室外：有顶无墙的过渡空间（如走廊、凉亭、门廊）
