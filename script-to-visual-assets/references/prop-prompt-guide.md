# 道具照片提示词完整规范

## 一、输出结构（固定字段顺序）

每条道具照片提示词包含以下字段，顺序不可调换：

```
名称：<道具名>，<道具类型简述>
描述：<形态>，<尺寸>，<材质>，<颜色>。
特征：<特殊细节描述>。
构图规范：<完整构图规范文本>
[视觉风格：<风格后缀>]
```

---

## 二、字段填写规范

### 名称
- 格式：`道具名，道具类型简述`
- 示例：`匕首，军用短刀` / `玉佩，古代信物` / `通讯器，赛博设备`

### 描述
- 必须包含：形态、尺寸（全长/尺寸数据）、材质、颜色
- 形态：直刃/弯刃/圆盘/方形/不规则等
- 尺寸：具体数值（如"全长20厘米"）
- 材质：金属/木质/布质/皮质/碳纤维等
- 颜色：具体颜色+质感（如"银色哑光"/"黑色磨砂"）
- 示例：`直刃短刀，全长20厘米，黑色碳纤维防滑握把，银色哑光不锈钢刀身。`

### 特征
- 描述道具独特细节：磨损、血迹、锈迹、刻字、纹路、发光部件等
- 无特殊特征时写：`无明显特征`
- 示例：`刀刃尖锐且带有一道干涸的暗红色血迹。`

---

## 三、构图规范（核心模块）

### 视图布局结构

```
高质量写实道具多角度展示图，横向构图，
以 2 行 3 列的干净网格整齐排版，
展示道具的六个极正视角。
纯白色纯净背景，专业产品影棚摄影，标准六视图参考。
六视图包括（必须是道具六视图）：
  绝对正前方视图
  绝对正后方视图
  绝对左侧视图
  绝对右侧视图
  绝对正上方俯拍视图
  绝对正下方仰拍视图
所有视图必须是同一件道具，材质、颜色、比例、结构完全一致。
```

### 投影与镜头参数

```
使用超长焦镜头或移轴镜头效果，将透视变形降到最低，
物体所有本该平行的边缘在画面中保持平行，接近正交投影。
每个视图都像在专业产品影棚中用三脚架精密校准拍摄，
构图绝对端正，物体在每个格子中居中，无任何倾斜、旋转或透视畸变。
```

### 禁止项清单（必须完整列出）

```
画面不得出现任何人物、角色、人群、人影等；
不得出现手、脚、人脸、场景、建筑、自然景观；
无其他道具；
必须无文字、无水印、无 logo、无 UI 元素；
不要任何剧情事件；
保持道具本体清晰、保持完整轮廓、保持所有角度的材质和结构一致。
```
