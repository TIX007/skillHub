# 人物形象提示词完整规范

## 一、输出结构（固定字段顺序）

每条人物形象提示词包含以下字段，顺序不可调换：

```
名称：<角色名>，<身份简述>
描述：<身份>，<性别>，<年龄>，身高<数值>厘米，<体型>，<发型发质>，<发色>，<脸型>，<瞳色>，<肤色>。
服装：<上衣>，<下装>，<鞋>，<帽>，<配饰>。
特征：<特殊外貌标记>。
构图规范：<完整构图规范文本>
[视觉风格：<风格后缀>]
```

---

## 二、字段填写规范

### 名称
- 格式：`角色名，身份简述`
- 示例：`少年陈峰，17岁高中生` / `剑仙苏雪，20岁女剑修` / `特工李默，30岁男特工`

### 描述
- 必须包含：身份、性别、年龄、身高（厘米）、体型、发型、发质、发色、脸型、瞳色、肤色
- 全部使用客观可量化描述
- 示例：`学生，男性，17岁，身高178厘米，匀称体型，稍乱短发，发质软，黑色发色，青涩脸庞，黑色瞳色，白皙肤色`

### 服装
- 逐件描述：上衣、下装、鞋、帽（无帽写"无帽"）、配饰（无配饰写"无配饰"）
- 每件需注明颜色+材质/款式
- 示例：`蓝白相间高中长袖校服上衣，蓝白相间校服长裤，白色运动鞋，无帽，无配饰`

### 特征
- 描述角色独特外貌标记：疤痕、淤青、纹身、胎记、痣、特殊瞳色等
- 无特殊特征时写：`无明显特征`
- 示例：`左脸颧骨处有轻微青色淤青痕迹`

## 三、构图规范（核心模块）

### 视图布局结构

```
高质量专业角色设定图，横向构图，纯白色纯净背景，中性摄影棚灯光，平光布光；
布局结构（必须是角色四视图）：
  正面面部头部特写（占图片水平 1/3 的空间）
  + [全身正面视图 + 全身左侧面视图 + 全身背面视图]（占图片水平剩余 2/3 的空间，并列排列）
四个视图中间用淡灰色(#E2E2E2)的2px细线分割
无任何道具或背景物体。
```

### 光影参数

```
中性摄影棚灯光，柔和的前侧光，清晰的轮廓定义，自然的肤色，
面部清晰服装可辨识，平视镜头，完整全身，无裁剪。
```

### 禁止项清单（必须完整列出）

```
不得出现任何道具/武器/食物/饮料/手持物（角色必须空手）；
不得出现复杂动作、情绪表情、面部遮挡；
不得出现环境背景（仅白色）；
不得出现其他角色；
确保所有视图中的面部特征、发型、体型和服装保持一致；
不得出现文字、水印、标签、UI元素；
无背景场景，无过度风格化，纯 Naive 样貌。
```
