# A股智能持仓监控与投研助手

> ⚠️ **重要声明**：本 Skill 所有分析仅为信息整理与数据分析，不构成任何投资建议。股市有风险，投资需谨慎，请独立决策。

---

## 📖 简介

A 股智能持仓监控与投研助手，专为 A 股个人投资者打造的 AI 盯盘 & 分析工具。支持截图识别持仓、实时异动监控、新闻舆情聚合、多维度技术/基本面分析，以及分级投资建议输出。

## ✨ 核心能力

| 能力           | 说明                             |
| ------------ | ------------------------------ |
| 📸 **截图识股**  | 上传持仓/自选股截图，自动 OCR 提取股票信息并建立监控池 |
| 🚨 **异动监控**  | 价格/量能/资金/技术/事件五维异动实时预警         |
| 📰 **新闻舆情**  | 自动聚合公司公告、行业新闻、市场舆情，利好利空标注      |
| 📊 **多维度分析** | 技术面 + 资金面 + 基本面 + 消息面，全维度覆盖    |
| 🎯 **分级建议**  | 短线/中线/长线三维操作建议 + 风险等级 + 免责声明   |
| 📋 **持仓管理**  | 实盘/模拟/自选三类标签，盈亏统计、板块集中度分析      |

## 🚀 快速开始

### 安装

Skill 文件位于 `~/.workbuddy/skills/a-stock-monitor/`，安装后即可使用。

### 前置依赖

本 Skill 依赖以下两个金融数据 Skill（需一并安装）：

| Skill                      | 用途                         |
| -------------------------- | -------------------------- |
| `neodata-financial-search` | 自然语言金融数据搜索（行情、财报、板块、宏观等）   |
| `westock-data`             | 结构化行情数据（技术指标、筹码、资金流向、龙虎榜等） |

### 三步上手

**1. 录入选股/持仓**

方式一：直接上传持仓截图（支持主流券商 APP 截图）

```
[上传持仓截图]
```

方式二：手动输入股票代码

```
添加监控：贵州茅台 600519、宁德时代 300750
```

**2. 开启监控**

```
开启监控
```

→ 自动对监控池全量检查异动，有异动则预警。

**3. 深度分析**

```
分析 600519
```

→ 完整的多维度分析 + 操作建议。

## 📋 常用命令速查

### 持仓管理

| 命令             | 说明            |
| -------------- | ------------- |
| `添加监控 [代码/名称]` | 将股票加入监控池      |
| `删除 [代码]`      | 从监控池移除        |
| `查看持仓`         | 展示完整持仓清单      |
| `持仓复盘`         | 持仓组合分析 + 调仓建议 |
| `清空持仓`         | 清除全部持仓数据      |

### 盯盘与异动

| 命令               | 说明         |
| ---------------- | ---------- |
| `开启监控` / `开始盯盘`  | 全量检查异动     |
| `调整监控阈值 涨跌±4%`   | 自定义异动阈值    |
| `关闭成交量提醒`        | 禁用指定异动维度   |
| `今日异动汇总`         | 当日所有异动个股汇总 |
| `异动原因 [代码]`      | 深度溯源异动原因   |
| `历史异动 [代码] [N天]` | 回溯历史异动记录   |

### 分析研究

| 命令              | 说明               |
| --------------- | ---------------- |
| `分析 [代码]`       | 单只个股深度分析         |
| `最新新闻` / `最新公告` | 监控池个股最新资讯        |
| `龙虎榜`           | 当日龙虎榜 + 机构游资动向   |
| `选股 [条件]`       | 按条件筛选（如"低估值高股息"） |
| `对比 A vs B`     | 两只股票横向对比         |
| `板块分析 [板块名]`    | 板块整体走势分析         |

### 复盘总结

| 命令     | 说明                |
| ------ | ----------------- |
| `今日复盘` | 当日盘面总结 + 持仓表现     |
| `本周复盘` | 周度收益率 + 胜率 + 最大回撤 |
| `明日预判` | 盘后关键观察信号整理        |

## ⏰ 时段模式

Skill 根据当前时间自动切换工作模式：

| 时段     | 时间               | 模式                 |
| ------ | ---------------- | ------------------ |
| 盘前     | 09:00 - 09:25    | 隔夜外盘回顾、盘前公告、竞价异动   |
| 盘中     | 09:30 - 15:00    | 实时异动监控、分时走势、资金流向   |
| 盘后     | 15:00 - 次日 09:00 | 收盘复盘、龙虎榜、公告解读、明日预判 |
| 周末/节假日 | 全天               | 本周复盘、持仓深度分析、下周展望   |

## 📊 分析维度详解

### 技术面

- 均线系统（MA5/MA10/MA20/MA60）
- MACD（金叉/死叉/背离）
- KDJ、RSI 等常用指标
- 支撑位/压力位
- 量价配合分析

### 资金面

- 主力资金净流入/流出
- 北向资金（沪深股通）买卖
- 融资融券余额变化
- 筹码成本分布

### 基本面

- PE/PB 估值水平
- 近期业绩（营收、净利润、增速）
- 行业地位与竞争优势
- 机构评级与目标价

---

## ⚠️ 风险提示与限制

### 已知限制

- 龙虎榜/大宗交易/融资融券仅支持沪深（sh/sz）
- 筹码成本仅支持沪深京 A 股（sh/sz/bj）
- 港股/美股数据覆盖不如 A 股全面
- 新闻舆情基于公开搜索，可能存在延迟
- 截图 OCR 识别精度取决于截图清晰度和排版

### 合规声明

- 不提供精准买卖点位
- 不承诺收益，不诱导交易
- ST/高波动个股重点风险警示
- 所有分析仅供参考，不构成投资建议
