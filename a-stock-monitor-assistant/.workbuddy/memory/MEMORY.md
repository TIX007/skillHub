## T 操作推荐系统（模块 8）

### 核心算法
- **维度A**（0-50分）：相对250天低点位置 = (P-L)/(H-L)，区间越低分越高
- **维度B**（0-50分）：近3-5日主力资金流向趋势，连流入=50，连流出=0
- **总分S = A+B**，映射5段：≥80→正T70%；65-79→正T55%；50-64→各35%；35-49→反T55%；<35→反T70%

### 仓位规则
- 底仓30%（不动）+ 机动仓70%（做T专用，单次1/3–1/2）

### 触发指令
- `T操作分析 [代码]`、`正反T建议 [代码]`、`做T分析 [代码]`

## 自进化记忆系统

### 记忆块存储
- 会话日志：`.workbuddy/memory/YYYY-MM-DD.md`
- 记忆索引库：`.workbuddy/memory/MEMORY.md`（本文件）
- 推送状态：`.workbuddy/push_state.json`（自动创建）

### 睡眠反思
- 每日反思：交易日 15:00-15:30 自动触发
- 每周反思：每周五收盘后自动触发

### 自进化参数
- 异动阈值自动调整规则：连续3次虚假→收紧10%，连续3次漏报→放宽10%
- 分析权重：用户连续质疑某维度→自动降低权重
