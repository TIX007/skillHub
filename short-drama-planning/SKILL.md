# 短剧策划与AI生产资产管理技能

## 技能定位

将故事梗概、完整剧本或小说原文，自动拆解为竖屏短剧全链路生产资产。覆盖剧本结构化拆解、人物/场景/道具资产建档、情绪与动作双脚本生成、影视工业标准分镜设计、逐镜头AI提示词工程优化、资产持久化存储与跨项目复用。

---

## 输入参数

| 参数名 | 必填 | 说明 |
|--------|------|------|
| project_name | 是 | 项目名称，用于资产归档命名 |
| drama_type | 是 | 题材类型（都市逆袭/古风甜宠/悬疑推理/战神赘婿等） |
| target_platform | 否 | 目标平台，默认抖音，可选红果短剧/视频号/快手 |
| episode_duration | 否 | 单集时长，默认60秒，单位：秒 |
| input_mode | 是 | 输入模式：`outline`（梗概生成）/ `script`（完整剧本拆解） |
| input_text | 是 | 故事梗概文本或完整剧本内容 |
| art_style | 否 | 视觉画风，默认写实真人风，可选古风二次元/真人写实/漫画分镜风 |
| reuse_asset_ids | 否 | 复用已有资产ID列表，格式：人物ID列表+场景ID列表 |

| 序号 | 文件名 | 内容 |
|------|--------|------|
| 1 | 项目总览.md | 项目基础信息、分集大纲、核心冲突与爽点排布 |
| 2 | 人物资产库.json | 全角色标准化档案，含唯一ID、外貌服饰、性格、提示词模板 |
| 3 | 场景资产库.json | 全场景标准化档案，含唯一ID、环境、光影、氛围、提示词模板 |
| 4 | 道具资产库.json | 关键道具档案，含唯一ID、外观、出场场次、提示词标签 |
| 5 | 分镜执行表.csv | 完整分镜表，含运镜、拍摄手法、动作、情绪、关联资产ID |
| 6 | AI生成提示词集.md | 逐镜头文生图提示词、图生视频提示词、统一负面提示词 |

## 完整执行工作流

### 阶段1：项目初始化与剧本解析

1. 接收输入参数，校验输入模式与文本完整性
2. 若为 `script` 模式：自动拆分场次、对白、旁白、动作描写
3. 若为 `outline` 模式：先扩写为标准分集剧本，再执行拆解
4. 统计核心要素数量：主要人物数、核心场景数、关键道具数

### 阶段2：核心资产提取与建档

遍历剧本内容，为每一项资产生成唯一ID与完整档案。详细字段规范参见 `references/asset-schemas.md`。

**人物资产**：姓名、身份定位、外貌特征、常服/特殊服饰、性格标签、标志性表情、声线特征、正向提示词模板、负面排除项

**场景资产**：场景名称、空间类型、时间天气、光影基调、氛围色调、固定陈设、关联道具、提示词模板

**道具资产**：道具名称、外观细节、功能属性、出场关键场次、视觉特征标签

所有资产存入对应JSON文件，同步写入资产索引。

### 阶段3：脚本深度拆解

基于场次内容生成两套并行脚本：

1. **情绪脚本**：按台词节点标注人物情绪等级（1-10）、情绪类型、情绪变化曲线，匹配对应表情与肢体状态
2. **动作脚本**：拆解每句台词对应的肢体动作、走位、道具交互、人物互动，控制单镜头动作复杂度，适配AI视频生成稳定性

### 阶段4：分镜与拍摄手法设计

按竖屏短剧视听语言规则，为每个镜头生成完整分镜字段。详细标准参见 `references/storyboard-standards.md`。

- **基础信息**：镜号、场次、对应时长、所属集数
- **镜头语言**：景别（特写/近景/中景/全景）、机位角度（平视/仰拍/俯拍/斜拍）、运镜方式（固定/推镜/拉镜/跟拍/摇镜）、拍摄手法（正反打/过肩/主观视角/空镜转场）
- **画面内容**：核心画面描述、人物站位、动作细节、环境层次
- **关联资产**：对应人物ID、场景ID、道具ID，实现引用式调用
- **声音信息**：台词/旁白、情绪基调、关键音效提示

### 阶段5：逐镜头AI提示词生成与优化

基于分镜内容 + 关联资产模板，自动组装双版本提示词。详细工程规范参见 `references/prompt-engineering.md`。

1. **文生图提示词**：画风前缀 + 场景资产描述 + 人物资产描述 + 动作表情 + 构图光影 + 画质参数
2. **图生视频提示词**：精简主体动作 + 运镜动态 + 环境氛围变化，控制动作幅度，避免人物崩坏
3. **全局负面提示词**：统一畸形、崩坏、穿模、低画质等排除项，全项目复用

所有提示词与镜号一一对应，支持批量导出。

### 阶段6：资产持久化存储

1. 按 `项目名称/资产库/` 目录结构输出所有JSON档案
2. 生成 `资产索引.json`，记录所有资产ID、名称、类型、文件路径
3. 输出复用说明：后续调用时传入 `reuse_asset_ids` 参数即可直接加载对应资产

### 阶段7：结果校验与输出

1. 校验资产ID唯一性、分镜与台词对齐度、提示词与资产关联正确性
2. 按指定格式输出全部产物
3. 返回项目唯一标识，用于后续续作生成、镜头补拍、资产更新

## 资产数据规范

完整字段定义与JSON Schema参见 `references/asset-schemas.md`。以下为核心示例：

**人物资产示例**：
```json
{
  "character_id": "char_001",
  "name": "林晚",
  "role": "女主",
  "appearance": "22岁，清冷鹅蛋脸，黑长直长发，杏眼，肤色白皙",
  "costume": "日常：白色衬衫+黑色西装裤；宴会：酒红色吊带长裙",
  "personality": "外冷内热，坚韧冷静",
  "prompt_template": "年轻女性，{appearance}，{costume}，{emotion}表情，{action}",
  "negative_prompt": "畸形手指，面部崩坏，五官扭曲，多肢体"
}
```

**分镜表核心字段**：

| 镜号 | 场次 | 时长 | 景别 | 运镜 | 拍摄手法 | 画面内容 | 动作 | 台词 | 人物ID | 场景ID | 文生图提示词 |

## 调用示例

### 输入
```
project_name: 都市逆袭之千金归来
drama_type: 都市逆袭
input_mode: outline
input_text: 女主林晚被继妹陷害赶出家门，三年后以集团总裁身份回归，在宴会上当众打脸继妹
art_style: 真人写实风
episode_duration: 60
```

### 输出
1. 自动扩写3集标准短剧剧本
2. 生成林晚、继妹、宴会现场等人物+场景资产档案
3. 输出12个镜头的完整分镜表，含正反打、特写打脸、全景宴会等运镜设计
4. 逐镜生成对应真人写实风提示词
5. 归档全部资产并生成索引ID，支持后续剧集复用

完整输出示例参见 `references/output-examples.md`。

---

## 约束与注意事项

1. 所有分镜默认适配9:16竖屏画幅，镜头语言优先符合短视频平台观看逻辑
2. 单镜头时长控制在3-8秒，开篇前3秒必须设置强钩子镜头
3. 资产ID全局唯一，同一项目内禁止重复，跨项目可通过ID直接复用
4. 提示词生成默认适配国内主流AI视频模型（可灵、Seedance），可根据目标模型调整语法结构
5. 自动规避违规内容，对暴力、低俗、敏感场景执行温和化处理并标注风险
6. 所有输出资产格式标准化，支持直接被后续剪辑、配音、渲染类Skill调用
