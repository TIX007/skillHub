# 竖屏分镜标准与镜头语言词典

## 画幅规范

- **标准画幅**：9:16 竖屏（1080x1920 像素）
- **安全区**：上下各留 10% 安全区，核心信息置于中间 80% 区域
- **字幕区**：底部 15% 预留字幕空间，重要画面避开此区域

---

## 景别定义

| 景别 | 取景范围 | 适用场景 | AI生成提示 |
|------|----------|----------|------------|
| 大特写 | 局部细节（眼睛、嘴唇、手指） | 情绪爆发、关键道具特写 | "extreme close-up shot" |
| 特写 | 面部为主 | 情绪传达、反应镜头 | "close-up shot, face filling frame" |
| 近景 | 胸部以上 | 对话场景、表情变化 | "medium close-up shot" |
| 中景 | 腰部以上 | 动作交互、双人对话 | "medium shot" |
| 全景 | 全身+部分环境 | 环境交代、入场出场 | "full shot, full body visible" |
| 远景 | 人物占画面1/4以下 | 场景建立、氛围营造 | "wide shot, establishing shot" |

---

## 机位角度

| 角度 | 定义 | 情感效果 | AI提示 |
|------|------|----------|--------|
| 平视 | 镜头与人物眼睛等高 | 客观、平等 | "eye-level angle" |
| 仰拍 | 镜头低于人物向上 | 威压、强势、高大 | "low angle shot, looking up" |
| 俯拍 | 镜头高于人物向下 | 弱势、渺小、被俯视 | "high angle shot, looking down" |
| 斜拍 | 镜头倾斜 | 不安、紧张、失衡 | "Dutch angle, tilted camera" |
| 鸟瞰 | 正上方俯视 | 全局、上帝视角 | "bird's eye view, top-down" |

---

## 运镜方式

| 运镜 | 定义 | 适用场景 | AI提示（图生视频） |
|------|------|----------|-------------------|
| 固定 | 镜头不动 | 对话、静态情绪 | "static camera, fixed shot" |
| 推镜 | 镜头向主体靠近 | 聚焦情绪、发现关键 | "slow push-in, camera moves forward" |
| 拉镜 | 镜头远离主体 | 揭示环境、疏离感 | "pull-back, camera moves backward" |
| 跟拍 | 镜头跟随人物移动 | 行走、追逐 | "tracking shot, following subject" |
| 摇镜 | 镜头原地旋转 | 扫视环境、反应链 | "pan shot, camera rotates" |
| 环绕 | 镜头绕主体旋转 | 高光时刻、英雄登场 | "orbit shot, camera circles subject" |
| 升降 | 镜头上下垂直移动 | 揭示高度、气势 | "crane shot, vertical movement" |
| 手持 | 轻微抖动模仿手持 | 紧张、纪实感 | "handheld camera, slight shake" |

## 拍摄手法

| 手法 | 定义 | 适用场景 |
|------|------|----------|
| 正反打 | 两个对话人物交替出现 | 对话场景、冲突对峙 |
| 过肩 | 越过一人肩部拍另一人 | 对话、对峙 |
| 主观视角 | 模拟角色视角 | 发现、震惊、第一人称体验 |
| 空镜转场 | 无人物的场景镜头 | 时间过渡、情绪留白 |
| 前后景 | 前景人物虚化+后景人物清晰 | 偷窥、暗中观察 |
| 镜中镜 | 通过镜子/屏幕拍摄 | 自我审视、监控视角 |

## 转场方案

| 转场类型 | 适用场景 | 实现方式 |
|----------|----------|----------|
| 硬切 | 快节奏场景切换 | 直接切换，无过渡 |
| 叠化 | 时间流逝、回忆 | 前一画面淡出+后一画面淡入 |
| 黑场 | 情绪断点、震惊 | 画面渐黑后切入新画面 |
| 白场 | 闪回、记忆 | 画面过曝变白后切入 |
| 模糊转 | 梦境、恍惚 | 焦点模糊后重新聚焦 |
| 动作匹配 | 连续动作跨场景 | 前一场景动作结束=后一场景动作开始 |

## 竖屏短剧镜头规则

### 时长控制

| 镜头类型 | 推荐时长 | 说明 |
|----------|----------|------|
| 钩子镜头（开篇） | 3-5秒 | 前3秒必须抓住注意力 |
| 对话镜头 | 3-6秒 | 单句台词对应一个镜头 |
| 动作镜头 | 3-8秒 | 单一动作完整呈现 |
| 反应镜头 | 2-4秒 | 表情反应快速切换 |
| 全景镜头 | 4-6秒 | 环境交代不拖沓 |
| 高潮镜头 | 5-8秒 | 给足情绪释放空间 |

### 钩子镜头设计（黄金3秒）

开篇前3秒必须设置强钩子，以下为常用钩子类型：

| 钩子类型 | 画面设计 | 示例 |
|----------|----------|------|
| 冲突前置 | 直接呈现冲突高潮画面 | 红酒泼脸特写 |
| 悬念倒叙 | 先展示结果再倒叙 | 女主站在高处俯视 |
| 反差对比 | 身份反转对比画面 | 乞丐装vs总裁装并置 |
| 对峙特写 | 人物对峙的面部特写 | 两人怒视对方 |
| 道具特写 | 关键道具大特写 | 一份遗嘱/一张照片 |

### 节奏控制

- **单集60秒**：8-12个镜头，平均每镜头5-6秒
- **情绪曲线**：每15秒一个小波动，每30秒一个大波动
- **对话密度**：对话镜头不超过总镜头的60%
- **动作复杂度**：单镜头内动作不超过2个连续动作，避免AI视频生成崩坏

## 分镜表完整字段定义

| 字段 | 说明 |
|------|------|
| shot_id | 镜号，格式 集号-镜号（如 1-03） |
| scene | 场次编号 |
| duration | 时长（秒） |
| episode | 所属集数 |
| shot_size | 景别 |
| angle | 机位角度 |
| movement | 运镜方式 |
| technique | 拍摄手法 |
| visual_desc | 核心画面描述 |
| character_pos | 人物站位 |
| action | 动作细节 |
| dialogue | 台词/旁白 |
| emotion | 情绪基调 |
| sound_effect | 关键音效提示 |
| character_ids | 关联人物ID |
| scene_id | 关联场景ID |
| prop_ids | 关联道具ID |
| transition | 转场方式（与下一镜） |
| txt2img_prompt | 文生图提示词 |
| img2video_prompt | 图生视频提示词 |
