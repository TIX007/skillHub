## 快速开始

### 第一步：获取高德API密钥

1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 点击右上角"注册"按钮，注册开发者账号
3. 登录后进入控制台
4. 点击"创建应用"，填写应用名称（如：地图规划助理）
5. 在应用中点击"添加Key"，选择"Web服务"类型
6. 复制生成的API Key

### 第二步：配置环境变量

**Windows系统：**

```cmd
set AMAP_API_KEY=你的API密钥
```

**Linux/Mac系统：**

```bash
export AMAP_API_KEY=你的API密钥
```

**永久配置（推荐）：**

创建 `.env` 文件：

```
AMAP_API_KEY=你的API密钥
```

### 第三步：开始使用

配置完成后，直接使用自然语言指令即可：

```
帮我生成北京市全能游玩地图
```

## 环境配置

### 系统要求

- Node.js >= 14.0.0
- 网络连接
- 高德地图API密钥

### 安装步骤

1. **克隆或下载项目**
   
   ```bash
   git clone <项目地址>
   cd map-planning-assistant
   ```

2. **配置环境变量**
   
   ```bash
   cp .env.example .env
   # 编辑 .env 文件，填入你的API密钥
   ```

3. **安装依赖（可选）**
   
   ```bash
   npm install
   ```

4. **运行测试**
   
   ```bash
   npm test
   ```

### 验证配置

运行以下命令验证配置是否正确：

```bash
node -e "console.log('API Key:', process.env.AMAP_API_KEY ? '已配置' : '未配置')"
```

## 功能详解

### 意图识别

系统支持以下意图类型：

| 意图类型  | 触发关键词        | 示例            |
| ----- | ------------ | ------------- |
| 全场景地图 | 全能、全套、全部     | 帮我生成北京市全能游玩地图 |
| 单场景地图 | 遛狗、跑步、溜娃、美食等 | 帮我做杭州西湖区溜娃地图  |
| 用户画像  | 画像、偏好        | 查看我的用户画像      |
| 历史游历  | 历史、游历、足迹     | 调取历史游历城市      |
| 本地活动  | 活动、展会、市集     | 推送本周本地活动      |
| 旅行模式  | 旅行、自驾、游      | 开启旅行模式规划3日自驾游 |
| 人文讲解  | 讲解、介绍、历史     | 讲解开封鼓楼人文历史    |

### 输出格式

每次生成地图包含以下内容：

1. **头部信息**
   
   - 地图主题
   - 所属城市
   - 适配人群
   - 建议游玩时长

2. **点位推荐**
   
   - 分场景TOP5优质点位
   - 评分、地址、人均消费
   - 最佳游玩时间

3. **路线规划**
   
   - 按区域拆分路线
   - 总距离、预计用时
   - 游览顺序建议

4. **活动推荐**
   
   - 同城近期活动
   - 活动时间、地点、票价

5. **个人地图**
   
   - 高德个人地图二维码
   - 地图链接
   - 使用说明

6. **温馨提示**
   
   - 个性化建议
   - 注意事项

## 八大场景地图

### 1. 遛狗地图 🐕

**适用人群：** 养宠人士、宠物爱好者

**检索内容：**

- 宠物友好公园
- 开放式草坪
- 宠物饮水点
- 宠物厕所
- 宠物咖啡店
- 宠物医院

**使用示例：**

```
帮我做北京朝阳区遛狗地图
找上海宠物友好公园
生成广州遛狗地图
```

**输出特点：**

- 标注宠物友好区域
- 标注禁养区域
- 推荐最佳遛狗时间（早晨6:00-9:00，傍晚17:00-19:00）
- 附带温馨提示（牵引绳、清理排泄物等）

## 个人地图生成

### 功能说明

基于高德 `maps_schema_personal_map` API 创建个人地图：

- 批量导入所有打卡点到个人地图
- 生成高德可识别的二维码
- 用户扫码直达高德App查看全量打卡点

### 使用方式

1. **生成地图**
   
   系统会自动创建个人地图，无需额外操作。

2. **查看地图**
   
   - 扫描输出中的二维码
   - 或点击地图链接

3. **使用地图**
   
   - 在高德App中查看全部打卡点位
   - 支持一键导航到任意点位
   - 可分享给好友或保存到相册

### 点位限制

- 单次最多创建包含50个点位的地图
- 超过50个点位时自动分批创建
- 每批生成独立的二维码和链接

### 坐标说明

- 经纬度用逗号分隔（如：116.473,39.942）
- 自动验证坐标有效性
- 过滤超出中国范围的无效坐标

## 常见问题

### Q1: 提示"AMAP_API_KEY未配置"

**解决方案：**

1. 检查环境变量是否正确设置

2. 运行以下命令验证：
   
   ```bash
   echo $AMAP_API_KEY  # Linux/Mac
   echo %AMAP_API_KEY%  # Windows
   ```

3. 确保密钥没有多余空格

---

### Q2: API请求失败

**可能原因：**

- API密钥无效或已过期
- 网络连接问题
- API调用次数已用完

**解决方案：**

1. 检查API密钥是否正确
2. 检查网络连接
3. 登录高德开放平台查看调用统计
4. 等待配额重置

---

### Q3: 搜索结果为空

**可能原因：**

- 城市名称不正确
- 搜索词过于具体
- 该地区POI数据较少

**解决方案：**

1. 使用标准城市名称（如"北京"而非"帝都"）
2. 尝试更通用的关键词
3. 扩大搜索范围

---

### Q4: 二维码无法在高德App打开

**可能原因：**

- `sceneType`参数错误
- 坐标格式不正确
- 坐标超出中国范围

**解决方案：**

1. 确保使用最新版本
2. 检查坐标格式
3. 联系技术支持

---

### Q5: 如何提高推荐质量

**建议：**

1. 多使用几次，系统会自动学习偏好
2. 设置常驻城市
3. 明确指定场景需求
4. 指定区域范围
